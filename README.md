# Blocks for Samaya

A quiet counting game for a three-year-old. Numbers 1–5, the Kannada word and the English word, a tower of planets, and a together screen where two groups join.

Play it: https://poornimajagannath.github.io/blocks-for-samaya/

The page is one file. It speaks with the phone’s own voice, and it keeps working after the first load with no network.
